## 2. 功能验收矩阵

| 能力 | Given | When | Then |
|---|---|---|---|
| 热点 | 多周期跨平台快照 | 运行评分 | 速度/加速度/阶段可重放且有理由 |

## 3. 非功能验收

### 3.1 可恢复

- API、Workflow Worker、Desktop Worker 在各阶段被杀死，重启后继续或明确转入可处理失败。
- 相同 Activity 重放不产生重复 Artifact/帖子。
- 人审等待 24h 后仍能继续。

### 3.2 性能

在基准 Apple Silicon Mac 上记录而不是先拍脑袋承诺：

- 60 秒 1080x1920 的 proxy/final render P50/P95。
- ASR、OCR、Scene 各自实时倍率。
- Desktop CPU/内存/磁盘峰值。
- Control Plane 在 20 条/日的队列等待。

MVP 硬门槛：60 秒视频从已有 SourceAsset 到首个 proxy（不含外部生成式视频排队）≤10 分钟。

### 3.3 成本

- 每条 Project 分阶段显示估算/实际成本。
- 预算超限前暂停。
- 缓存命中不重复计费。
- Provider 切换后能对比质量/成本。

### 3.4 安全

- 日志扫描无 Token/Cookie/平台密码。
- Artifact URL 过期且越权不可读。
- FFmpeg 不支持任意协议/命令注入。
- Worker 只能执行注册的 Task Type。
- Webhook 重放无副作用。

## 4. Media Golden Tests

合成素材必须覆盖：

- CFR/VFR、29.97、30、60 fps。
- 多音轨、无音轨、旋转元数据、奇数尺寸。
- 前后黑帧、单帧闪白、冻结、短静音、长期静音。
- 已知 +120ms/-160ms 音画偏移。
- 静态/移动字幕、半透明文字、遮挡、透视文字。
- 双人交替/重叠说话、背景音乐很响。
- H.264/H.265/VP9/AV1（按平台/工具支持划分）。

测试比较：帧数/时长、关键帧图像指标、音频包络/响度、字幕 Marker 和 QA 报告。不同编码器不要求 MP4 二进制 hash 相同。

## 5. Connector 测试

三层：

1. Unit：脱敏响应 Fixture、错误映射。
2. Contract：Fake Server/录制协议，验证 Schema 和幂等。
3. Canary：专用测试账号/关键词，每日低频执行，单独告警。

Canary 失败只禁用对应 Capability，不让整个系统显示“正常但无数据”。

## 6. 发布混沌测试

- 上传 50% 断网。
- Submit 返回超时但实际已发布。
- Webhook 重复/乱序/延迟。
- OAuth 在上传后、提交前过期。
- 浏览器页面 selector 改变。
- Android App 升级、设备锁屏、USB 断开、当前账号错误。

期望：无重复帖子；状态可解释；需要用户时明确待办。

## 7. 上线检查表

- P0–P5 Exit Criteria 全通过。
- 依赖/模型/字体/音乐/二进制 SBOM 可生成。
- macOS 安装、升级、卸载和缓存清理已测试。
- 两平台官方发布能力/应用审核状态在 UI 可见。
- 浏览器/真机 Adapter 有 Kill Switch。
- 全库备份/恢复演练完成。
- 账号凭据恢复/撤销流程完成。
- 发布前手工应急路径文档完成。

## 8. MVP Definition of Done

在一台首期 macOS 机器和一套自托管 Control Plane 上，用户能从抖音/TikTok 热点或 URL 创建项目，生成结构重写/原片重剪版本和中英变体，审核后通过可用连接器发布，并在发布后回收指标；任一自动步骤失败均有明确原因、重试/降级/人工路径，且不会丢项目、泄漏凭据或重复发布。
