# 抖音发现连接器（source.douyin）

把抖音的发现信号（关键词/账号/榜单）归一化为 `TrendItemSnapshot`，供 M01 热点情报使用。

## 三条路径

| 模式 | 状态 | 说明 |
|---|---|---|
| 官方开放平台 | **未配置**（停止条件） | 需 `douyin_open_api_client_key/secret` 与 App 审核。未配置时返回 `UNCONFIGURED`，不静默失败。 |
| L4 公开信号适配器 | **实时抓取未启用** | 非官方接口签名/页面易变，涉及 ToS 与风控。解析层已实现并用录制 fixture 测试；实时 fetcher 未接入，需显式授权后用 f2（Apache-2.0，L4）等适配器。遇验证码/风控返回 `CHALLENGE`，转人工，不尝试绕过。 |
| 手工导入 | **始终可用** | 用户提供归一化 JSON（人工收集/平台导出）→ snapshots。连接器失效时的可靠回退。 |

## 中性采集响应格式

连接器只消费**平台中性**的归一化响应（本仓库自有格式，非抖音私有 API 结构）：

```json
{ "items": [ { "item_id": "...", "views": 120000, "likes": 8400, "rank": 7, "hashtags": ["ai"], "observed_at": "2026-07-22T00:00:00Z" } ] }
```

把真实抖音响应转成此格式的适配器就是需要真凭据/授权的部分（未实现）。缺失指标保留 `null`，绝不填 0（40 §3.2）。

## 停止条件（docs/implementation/53 §10）

- 启用官方路径需真实平台账号与 App 审核 → 提供凭据后再实现。
- 启用 L4 实时抓取需授权，且遇验证码/风控必停给人工。

在此之前，手工导入 + 录制 fixture 是工作路径。
